# Design Context — Nexus Commerce

- **Audience**: online shoppers (demo/portfolio visitors trying the purchase flow) and the store operator (single ADMIN who manages catalogue, stock, orders, and reads sales reports).
- **Use cases**: browse/search products, manage cart, checkout with mock payment, track orders; admin: catalogue CRUD, stock control, fulfilment transitions, revenue/order reporting with export.
- **Brand personality**: a serious small-business storefront — warm, editorial, trustworthy. Serif display type (Fraunces) for brand/product moments, Manrope for dense UI and admin tables. Warm paper background, deep pine green primary, ochre accent used sparingly. No gradients, no glass, no neon, no dark-mode gimmicks.
- **Implementation defaults**: React + Tailwind v4 (`@theme` tokens: ink/pine/ochre/paper), charts as hand-built SVG with data-table fallbacks, CSV export client-side, print stylesheet for reports. Grayscale hierarchy first; color only for semantics and primary actions.
